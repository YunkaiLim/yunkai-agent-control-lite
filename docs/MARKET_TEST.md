# Market Test — v0.1

## Hypothesis

Developers with multiple AI coding tools have enough “local stack visibility” pain to install a small dashboard and some will pay for a more complete local control plane.

## Price hypothesis

- Preview: free.
- Founding-user early access: US$29 lifetime.
- No subscription in the first test.

The price is intentionally visible before checkout exists. We want price reaction before building billing integration.

## 30-day decision window

Primary signal:

- 200 targeted landing-page visitors.
- 20 local preview downloads / installs.
- 8 users who reopen it on another day or explicitly request the next feature.
- 3 real paid early-access purchases after checkout is connected.

Interpretation:

- Traffic but almost no installs: positioning or trust problem.
- Installs but no repeat usage: product value problem.
- Repeat usage but no purchases: price / free boundary problem.
- Purchases plus unsolicited feature requests: continue.
- Requests are concentrated around one feature: build only that feature next.

## Interview prompts

Ask users after they have tried it:

1. What did you use before opening this dashboard?
2. Which status did you actually care about?
3. What would make you keep it installed?
4. What would you be nervous about this tool reading or controlling?
5. Would you pay US$29 once for the next version? Why / why not?

Do not ask “do you like it?” as the primary question.

## Next feature candidates — only after evidence

- MCP server inventory.
- Provider/model connection overview.
- Permission/Human Gate visibility.
- Explicit reviewed start/stop plan.
- Team policy export.

Do not build all five before users reveal which one matters.
